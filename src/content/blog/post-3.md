A confident-looking interface can hide a thin evidence base. This Kojima demonstration explores how to present an assessment so a reviewer can see what supports it and what could change it.

All records in this exercise are fictional. The confidence labels below are explanatory examples, not calibrated probabilities.

## Assess the claim, not the screen

Consider the claim: “A capacity reduction may affect the sample delivery window.” Confidence belongs to that claim. It does not automatically transfer to every supplier or shipment displayed beside it.

Record the reasoning in plain language:

| Dimension             | Sample review note                          |
| --------------------- | ------------------------------------------- |
| Source basis          | One fictional terminal notice               |
| Independent agreement | No separate confirmation yet                |
| Timing                | Notice overlaps the planned handling window |
| Missing context       | Terminal assignment is unverified           |

## Avoid counting repetition as corroboration

Three summaries may trace back to one notice. Treating them as three independent sources inflates apparent support.

In the sample brief, repeated references remain linked to their common origin. A separate supplier confirmation would add a different kind of evidence, but only for the claims it actually addresses.

## Explain what would change the view

A useful uncertainty note is actionable: “Confirming a different terminal would reduce the expected exposure. A matching terminal assignment and a revised handling estimate would strengthen the assessment.”

This helps the next reviewer find the missing evidence instead of debating an unexplained score.

## Keep consequence separate from confidence

An uncertain event can still merit review if its possible consequences are significant. Conversely, a well-supported minor change may not need escalation.

The demo treats consequence, urgency, and evidential confidence as separate questions. It does not calculate validated risk scores or offer predictive guarantees.
